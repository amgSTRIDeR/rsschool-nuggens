# Nuggens

**Nuggens** is a responsive nutrition tracking web application created as an educational project for the RS School **Landing Page** task.

The project is based on an original design and provides a simple interface for browsing food products, tracking daily nutrition, and managing product information.

## Features

- Responsive layout for desktop, tablet, and mobile devices
- Light and dark themes with saved user preference
- Product catalog with food and drink categories
- Product cards with nutrition information
- Product search and filtering
- Product sliders
- Product details modal
- Quantity controls
- Burger menu for smaller screens
- Shared header and footer
- Daily nutrition summary and intake overview

## Tech Stack

- HTML5
- SCSS
- Vanilla JavaScript
- Handlebars
- Vite
- modern-normalize

The project does not use JavaScript or CSS frameworks. Interactive components are implemented with vanilla JavaScript.

## Pages

- **Home** — nutrition dashboard, frequent products, meal analysis, daily summary, intake history, and calendar
- **Products** — searchable and filterable product catalog

## Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

Vite is configured with source maps enabled and code minification disabled.
